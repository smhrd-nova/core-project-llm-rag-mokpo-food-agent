# 📋 2026.09.07 「오늘 뭐 목포?」 UI/UX 멘토링 피드백 및 개선 방향

> **"오늘 먹을 목포를 검색하는 것이 아니라, AI가 설계한다"**라는 기존 비전에서 한 걸음 더 나아가, **사용자가 중심이 되어 장소를 고르고 AI가 옆에서 밀착 지원하는 '인터랙티브 AI 여행 플래너'**로 UX 방향성을 정교화한 멘토링 결과 정리입니다.

---

## 1. 전체 피드백 요약: 현재 기획 vs 멘토링 제안

| 구분 | 기존 기획 | 멘토링 개선 방향 |
| :--- | :--- | :--- |
| **여행 조건 입력** | 체크/입력 후 별도 AI 대화 단계 | 체크·선택을 메인으로 유지 (흐름 단절 방지) |
| **AI 대화 역할** | 필수적인 중간 단계 | 상시 호출 가능한 보조 기능 (`AI 가이드`) |
| **장소 선택** | 장소를 순차적으로 선택 후 마지막에 확인 | **선택과 동시에 타임라인 실시간 반영** |
| **일정 수정** | 별도 수정 프로세스 | 선택 화면에서 칸반보드 형태로 즉시 수정 |
| **일정 순서** | 고정된 흐름 | 드래그·이동 및 실시간 이동시간 재계산 |
| **홈 추천** | 단순 인기/Best 일정 위주 | Context 기반 큐레이션 (시즌 × 동행 × 상황) |
| **AI UI 위치** | 중간 단계 화면 | **우측 하단 플로팅 버튼 (Floating AI Assistant)** |
| **전체 UX** | 단계적(Step-by-step) 코스 생성 | 만들면서 결과를 동시에 확인하는 인터랙티브 구조 |

## 2. 핵심 피드백 상세 내용

### ① AI 대화를 별도 필수 단계로 두지 말 것
* **문제점:** 사용자가 이미 동행, 시간, 예산, 분위기 등을 선택했는데 갑자기 또 AI와 대화해야 하면 피로감이 누적되고 흐름이 끊김.
* **개선 방향:** 체크·선택은 빠르고 직관적인 메인 UX로 처리하고, AI 대화는 필수 단계가 아닌 **보조 UX**로 전환.

### ② 장소를 선택하는 순간 타임라인 실시간 생성
* **문제점:** 식당 → 카페 → 관광지를 다 고르고 나서야 마지막에 코스를 확인하는 방식은 직관성이 떨어짐.
* **개선 방향:** 화면을 **좌측(장소 탐색)**과 **우측(실시간 여행 타임라인)**으로 분할하여, 장소를 하나 고를 때마다 오른쪽에 즉시 일정과 이동 간격이 실시간으로 누적되는 구조 도입.

### ③ 칸반보드 형태의 자유로운 코스 수정
* **개선 방향:** AI가 일방적으로 짜준 코스를 그대로 따르는 것이 아니라, 사용자가 카드를 위아래로 잡고 움직이거나(드래그), 교체·삭제할 수 있어야 함. 순서 변경 시 **이동시간 및 예상 도착시간 자동 재계산** 기능 포함.

### ④ 홈 화면 Context 기반 큐레이션 강화
* 단순 인기순 조회가 아닌, 아래와 같은 실사용자 시나리오별 큐레이션으로 확장:
  * **시즌/상황:** 가을 노을 여행, 비 오는 날 목포, 목포항구축제 코스
  * **동행자:** 부모님과 천천히 걷는 목포, 아이와 함께, 커플 여행
  * **예산/이동수단:** 5만원으로 즐기는 목포, 차 없이 여행하는 목포

### ⑤ SNS 및 UGC 데이터 플라이휠 구조 정립
* 실제 여행 기록과 SNS 공유 데이터를 단순 후기로 끝내지 않고, `누구와 / 언제 / 어떤 상황에서 / 어떤 장소를 선택했는가`에 대한 **구조화된 Context 데이터**로 변환하여 다음 사용자 추천 알고리즘의 RAG 근거로 재활용.

## 3. 멘토링 반영 후 최종 User Flow (10단계)

1. **STEP 1. 홈:** 추천 여행 컨셉 및 다른 여행자의 실제 일정 탐색
2. **STEP 2. 기본 Context 입력:** 누구와 / 시간 / 예산 / 이동수단 / 취향을 빠른 선택형으로 입력
3. **STEP 3. 장소 탐색 + 코스 구성 (핵심 화면):** 좌측(장소 후보) / 우측(실시간 Live Timeline)
4. **STEP 4. AI 몽포리 상시 지원:** 우측 하단 `💬 몽포리에게 물어보기` 플로팅 버튼 활용
5. **STEP 5. 즉시 수정:** 장소 추가/삭제/교체 및 순서 변경 (이동시간 자동 재계산)
6. **STEP 6. 여행 시작:** 완성된 일정으로 실제 여행 진행
7. **STEP 7. 여행 중 지원:** 여행 중 실시간 위치 기반 장소 추천 및 일정 조정 요청
8. **STEP 8. 여행 기록:** 방문 장소·사진·평가를 활용한 AI 여행일지 생성
9. **STEP 9. 공유:** 서비스 내 공개 또는 SNS 공유
10. **STEP 10. 데이터 재활용:** 공개된 여행 경험을 구조화해 RAG/DB 추천에 반영

---

## 4. 향후 개발 우선순위 (Action Items)

1. **1순위 (User Flow 수정):** AI 대화를 필수 단계에서 제거하고 메인 탐색 흐름 가속화
2. **2순위 (코스 제작 UI 신설):** 좌측 장소 탐색 + 우측 Live Timeline 2분할 화면 구축
3. **3순위 (코스 편집 UX):** 드래그, 순서 변경, 삭제 및 이동시간 연동 기능 구현
4. **4순위 (플로팅 AI 구현):** 우측 하단 `몽포리` Floating AI Assistant 인터페이스 적용
5. **5순위 (홈 큐레이션 확장):** 동행자·시즌·상황별 테마형 큐레이션 UI 구성
